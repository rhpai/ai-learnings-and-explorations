# AI Learnings and Explorations

A repository for learning how AI systems work, investigating questions through experiments, and turning ideas into small projects.

## Learn

Notes and worked examples on AI concepts and techniques. Start here to understand how something works or find an example you can follow on your own.

## Explore

Experiments that start with a question, such as how changing a prompt affects the results. Entries will capture what was tried, what happened, and which questions are still open.

Start with [Tiny Transformer](explore/tiny-transformer/), a CPU experiment in learning to copy unseen digit sequences.

## Build

Small tools, demos, and prototypes that put ideas into practice. Look here for source code, instructions for running each project, and notes on the decisions that shaped it.
